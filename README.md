# ШМЕЛИ — детский центр в Кирове

Официальный сайт детского центра «Шмели» (Киров). Это статический мультистраничный сайт, созданный для того, чтобы родители могли узнать о центре и его занятиях, увидеть направления развития и связаться с командой.

## Зачем этот сайт

- **Рассказывает о центре.** Спорт, нейрогимнастика и арт-терапия — не «развивашки», а комплексное дошкольное развитие: тело, мозг и эмоции ребёнка.
- **Знакомит с философией.** Девиз центра — *«Единство, ловкость, интеллект»*, главное правило — *«У меня получилось!»*.
- **Ведёт к контакту.** На каждой странице есть ссылки на группу VK, страницу семейного центра «Вятка поколений» на VK, Яндекс Карты и встроенная карта с адресом.

## Содержание

- `index.html` — главная: о центре, три направления, главное правило, CTA.
- `directions.html` — направления: физическое развитие, подготовка к школе через нейрогимнастику, снятие напряжения через арт-терапию.
- `about.html` — о нас: философия «Больше, чем развивашки», ценности, девиз.
- `contacts.html` — контакты: адрес (Герцена, 10, 2 этаж), VK-ссылки, Яндекс Карта.
- `css/styles.css`, `js/main.js` — оформление (жёлто-чёрная тема шмеля) и интерактив (мобильное меню, анимации).
- `logo.webp`, `favicon.png` — фирменный знак центра.

## Технологии

Чистые HTML + CSS + JavaScript, без сборщиков и фреймворков. Сайт статический — хостится как GitHub Pages.
